# Contributing

## Developer Certificate of Origin (DCO)

Every commit in a pull request must include a DCO sign-off. Use:

```bash
git commit -s
```

That adds a `Signed-off-by: Your Name <your.email@example.com>` line to the commit message, certifying that you have the right to submit the work under the project's license. Read the full text at [developercertificate.org](https://developercertificate.org/).
